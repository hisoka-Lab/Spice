# 🍺 บาร์เสมือนจริง - Virtual Community Bar

เว็บแอพคอมมูนิตี้แบบบาร์เสมือนจริงที่ผสมผสานระหว่างการพูดคุย เกม และระบบเศรษฐกิจภายใน

## ✨ ฟีเจอร์หลัก

### 🍻 ระบบบาร์และแชท
- พูดคุยกับบาร์เทนเดอร์ที่จะตอบกลับอัตโนมัติ
- แชทกับผู้เล่นคนอื่นๆ ในบาร์
- ซื้อเหล้าให้ตัวเองหรือเลี้ยงคนอื่น
- ส่งข้อความพร้อมกับเหล้าที่สั่ง

### 💭 ร้านขายฝัน
- ขายเรื่องราวและความฝันของคุณเป็นเหรียญ
- ซื้อฝันจากผู้เล่นคนอื่น
- ฝันแบ่งเป็น 5 ประเภท: ความสุข, ความเศร้า, การผจญภัย, ความรัก, ความลึกลับ
- ระบบ e-commerce สำหรับการซื้อขายเรื่องราว

### 🗺️ เกมแมพ
- ตัวละครเดินได้ในแมพ 2D
- คุยกับ NPC เพื่อรับเควส
- ทำเควสเพื่อได้เหรียญและประสบการณ์
- ระบบเลเวลและการเลเวลอัพ

### 🪙 ระบบเศรษฐกิจ
- เหรียญในเกมสำหรับซื้อของต่างๆ
- ได้เหรียญจากการทำเควสและขายฝัน
- ใช้เหรียญซื้อเหล้า, ฝัน, และของอื่นๆ

## 🚀 การติดตั้งและรัน

### ข้อกำหนดระบบ
- Python 3.8+
- Django 4.2.7
- SQLite (ใช้เป็นฐานข้อมูลเริ่มต้น)

### ขั้นตอนการติดตั้ง

1. **Clone โปรเจค**
```bash
git clone <repository-url>
cd citygame
```

2. **ติดตั้ง dependencies**
```bash
pip install -r requirements.txt
```

3. **สร้างฐานข้อมูล**
```bash
python manage.py makemigrations
python manage.py migrate
```

4. **สร้างข้อมูลเริ่มต้น**
```bash
python manage.py setup_initial_data
```

5. **สร้าง superuser**
```bash
python manage.py createsuperuser
```

6. **รันเซิร์ฟเวอร์**
```bash
python manage.py runserver
```

7. **เข้าใช้งาน**
- เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8000`
- เข้าสู่ระบบด้วย superuser ที่สร้างไว้

## 🎮 วิธีเล่น

### การเริ่มต้น
1. เข้าสู่ระบบหรือสมัครสมาชิกใหม่
2. คุณจะได้เหรียญเริ่มต้น 100 เหรียญ
3. เลือกไปยังพื้นที่ต่างๆ ผ่านเมนูหรือแมพ

### ในบาร์ 🍺
- พิมพ์ข้อความเพื่อพูดคุย
- บาร์เทนเดอร์จะตอบกลับถ้าไม่มีคนอื่นพูด
- สั่งเหล้าให้ตัวเองหรือเลี้ยงคนอื่น
- ดูสถานะเหรียญและเลเวลของคุณ

### ในร้านฝัน 💭
- ดูฝันที่คนอื่นขาย
- ซื้อฝันที่สนใจด้วยเหรียญ
- ขายฝันของตัวเองโดยเขียนเรื่องราว
- เลือกประเภทและตั้งราคาฝัน

### ในแมพเกม 🗺️
- คลิกในแมพเพื่อเดิน
- คลิก NPC เพื่อรับเควส
- ทำเควสเสร็จเพื่อได้รางวัล
- เลเวลอัพเมื่อได้ประสบการณ์เพียงพอ

## 🎨 การปรับแต่ง

### เพิ่มเควสใหม่
1. เข้า Django Admin (`/admin/`)
2. ไปที่ Game > Quests
3. เพิ่มเควสใหม่พร้อมรางวัล

### เปลี่ยนข้อความบาร์เทนเดอร์
แก้ไขใน `game/views.py` ฟังก์ชัน `send_message()`:
```python
bartender_responses = [
    "ข้อความใหม่ของบาร์เทนเดอร์...",
    # เพิ่มข้อความอื่นๆ
]
```

### ปรับราคาเหล้า
แก้ไขใน `game/models.py` และ `game/views.py`:
```python
prices = {'beer': 10, 'whiskey': 25, 'cocktail': 20, 'wine': 30}
```
